# AtCoder アルゴリズムテンプレート集

## 0. 概要

- 元のコード：**51 本**（`.cpp` と `.c` が混在、すべて AC）。
- 整理結果：**18 個の再利用可能なテンプレート**。そのうち **21 本**のコードから
  整理・統合したもの。
- 残り **30 本**は入門文法、A 問題の個別ケース判定、問題固有の全探索／シミュレーション。
  [`NOT_TEMPLATES.md`](./NOT_TEMPLATES.md) にまとめ、無理にテンプレート化しない。
- すべてのテンプレートは **C++17** に統一し、`#include <bits/stdc++.h>` を使用
  （AtCoder の GCC 環境でそのまま使える。別コンパイラでは標準ヘッダに置換する）。
- 各テンプレートの冒頭に【用途 / 適用場面】【時間・空間計算量】
  【注意事項 / 境界条件】と出典問題を記載している。

> 規約：特に断らない限り、添字は **0-based**。問題の入力が 1-based の場合は、
> 読み込み後に 1 を引く（テンプレート 10 は 1-based 版も提供）。
> 「空間」列は、入力／出力自体が占めるメモリを含まない。

## 3. 使い方

各 `.cpp` は**そのまま解答に貼り付けられる独立した関数／構造体**であり、
`main()` を持たず、入力を読み込まない。典型的な使い方：

```cpp
#include <bits/stdc++.h>
using namespace std;

// テンプレートファイルの関数／構造体をここに貼り付ける

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<long long> a(n);
    for (auto& x : a) cin >> x;

    long long ans = sum_values_with_odd_frequency(a);  // テンプレート 03 の例
    cout << ans << '\n';
}
```

## 4. 共通の注意事項

1. **オーバーフロー**：累積和、積、場合の数を扱うときは `long long` を優先する。
   法が `1e18` に近いと加算でもオーバーフローするため、必要に応じて
   `__int128` を使う。
2. **添字**：テンプレートは既定で 0-based。問題の入力が 1-based なら、
   読み込み後に 1 を引く。元の番号を出力するときは 1 を足し戻す。
3. **ハッシュの計算量**：`unordered_map` / `unordered_set` は期待 O(1)、
   最悪 O(n)。厳密な最悪保証が必要な場合は `map` / `set` を使う（log が付く）。
4. **再帰の深さ**：テンプレート 11 は明示スタックに変更済み。それ以外の
   再帰解法では、n が大きいときのスタック溢れに注意し、必要なら反復に直すか
   スタックを拡張する。
5. **比較関数**：複数キーソートの比較関数は厳密弱順序を満たす必要がある。
   等しい場合は `false` を返し、tie-break を完全に書く。
6. **空入力**：すべてのテンプレートで空配列／空文字列を処理している。
   ただし呼び出し前に、問題が n >= 1 を保証しているか確認する。
7. **問題の差異**：テンプレートは「そのモデル」だけを扱う。たとえば
   テンプレート 06 は「任意の要素を取る」であり、「両端からしか取れない」
   ではない。テンプレート 15 の `'*'` は 1 文字に一致し、glob ではない。
   使う前にルールが一致しているか確認する。
